## Data administrator

The administrator and owner of all data (excluding third-party data) processed within this website
is [${globals.name}](${config.seo.domain}/).

## Cookies and user tracking

This website is designed with respect for privacy and **does not use any cookies**. The service does not create, store,
or overwrite cookies on the end device, nor does it track the user's browsing history through them.

## Infrastructure, security, and data storage

Network traffic and technical data pass through third-party servers to ensure the availability and security of the
website:

- **Cloudflare** and **Vercel** process connection data (such as IP addresses or request headers) for hosting, routing,
  and protection against abuse and DDoS attacks.
- **Google (Google Cloud Platform / Google Cloud Storage)** is responsible for processing selected resources and data
  stored externally, outside the main structure of this website.

## Web analytics

To analyze traffic and optimize usability, the website uses two analytics systems:

- **Umami Analytics** as a tool for collecting anonymized visit statistics. Data collected by Umami is stored on
  self-hosted servers in the Oracle Cloud Infrastructure (OCI), located within the European Union (Frankfurt, Germany).
- **Microsoft Clarity** as a system for studying interface interactions by generating activity heatmaps. Data collected
  within this service is stored on Microsoft servers.

## Data retention

All collected analytical data and technical logs are stored for a maximum period of **half a year (6 months)**, after
which they are permanently deleted.
